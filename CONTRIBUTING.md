# Contributing

Issues and pull requests are welcome.

- Open an issue to report a bug or suggest a change, or send a pull request against `main`.
- Keep changes small and run `cargo fmt`, `cargo clippy` and `cargo test` before you send them; CI runs the checks on every pull request.
- Releases are made only by the maintainer. Please do not create tags, GitHub releases or distribute builds of these apps.
- Copycraft is offline by design: changes that add network access or new entitlements will not be accepted.
